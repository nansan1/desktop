# Changelog (desktop shell)

The apps have their own changelogs in their repos. This is only the Windows shell.

## 1.0.0 (Nov 11, 2026)
- First version: Windows apps for Helm, Keel, Lodestar, Spinnaker, Holdfast and Fathom that open the live address (always the latest app version) and update their own shell from this repo's releases.
- Old desktop bridges kept (file opening, Lodestar backups to a chosen folder, Spinnaker PDF export), right-click spelling menu, links between apps, remembered window size, offline page.
